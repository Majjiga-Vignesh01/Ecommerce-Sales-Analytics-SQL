# E-Commerce Sales Analytics using SQL

## Project Overview
This project analyzes e-commerce sales data using SQL to generate business insights.

## Objectives
- Analyze total sales and revenue
- Identify top-selling products
- Analyze customer spending behavior
- Track monthly revenue trends
- Rank customers based on purchases

## SQL Concepts Used
- Joins
- Aggregate Functions
- GROUP BY
- Window Functions
- Ranking Functions

## Files
- ecommerce_sales.sql : Database creation and analysis queries

## Key Insights
- Top-performing products
- Highest-spending customers
- Monthly sales performance
- Customer purchase patterns

## Tools Used
- MySQL
- SQL
- GitHub
